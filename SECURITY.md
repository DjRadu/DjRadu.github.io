# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability on djradu.com, please report it responsibly.

**DO NOT** open a public GitHub issue for security vulnerabilities.

Instead, email us at: **info@djradu.com**

Please include:
- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Your contact information

## Response Timeline

- **Initial response:** Within 48 hours
- **Status update:** Within 1 week
- **Resolution:** We aim to fix critical issues within 30 days

## What happens next

1. We will acknowledge receipt of your report
2. We will investigate and verify the issue
3. We will develop and test a fix
4. We will release a patch and credit you (if you wish)

Thank you for helping keep DJ Radu secure!

## Scope

This policy applies to:
- djradu.com website
- GitHub repository
- Booking systems
- Customer data handling
